DOM 요소 선택: 선택자에 맞는 메서드 사용하기

1. CSS 선택자를 사용하는 `querySelector`와 `querySelectorAll`

    CSS 선택자를 그대로 사용하여 다양한 조건으로 요소를 찾을 수 있습니다.
    하나를 찾을 때와 조건에 맞는 모든 요소를 찾을 때 반환값이 다릅니다.
  • 사과
  • 바나나
  • 딸기

2. `getElementsByClassName`과 살아 있는 목록

    `getElementById`와 `getElementsByClassName`도 현재 사용할 수 있는 DOM 메서드입니다.
    `getElementById`는 요소 하나를 반환하고, `getElementsByClassName`은
    문서의 변경을 실시간으로 반영하는 `HTMLCollection`을 반환합니다.

3. 순회 도중 바뀌지 않는 목록이 필요할 때 배열로 변환하기

    `querySelectorAll`은 이런 문제가 없는 '고정된' `NodeList`를 반환하기 때문에 훨씬 안전합니다.
    `getElementsBy...`로 얻은 살아 있는 목록을 변경하면서 순회해야 한다면,
    현재 요소들을 먼저 배열로 변환하여 고정된 목록으로 사용할 수 있습니다.
